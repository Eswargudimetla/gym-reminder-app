📱 Gym Reminder App

A mobile application that helps users schedule gym/workout reminders and receive timely notifications so they never miss a workout. The app is built using Capacitor + JavaScript and runs on Android devices.

🚀 Features

⏰ Schedule gym/workout reminders

🔔 Local notifications on mobile

📱 Runs as a native Android app

⚡ Simple and lightweight UI

🔄 Easy to update and extend

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Mobile Framework: Capacitor

Platform: Android

Tools: Node.js, npm

📂 Project Structure
Gym Reminder App/
│── android/               # Android native project
│── www/                   # Web app build files
│── package.json           # Project dependencies
│── capacitor.config.json  # Capacitor configuration
│── .gitignore

▶️ How to Run Locally
1️⃣ Clone the repository
git clone https://github.com/Eswargudimetla/gym-reminder-app.git
cd gym-reminder-app

2️⃣ Install dependencies
npm install

3️⃣ Build the web app
npm run build

4️⃣ Sync with Android
npx cap sync android

5️⃣ Run on Android

Open the android/ folder in Android Studio and run the app on an emulator or physical device.
